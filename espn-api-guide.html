🏗 API Overview & Architecture

ESPN exposes three tiers of free, unauthenticated JSON APIs. No API key is required. All return application/json.

TierBase URLPurpose
Site site.api.espn.com/apis/site/v2/sports/soccer/{league}/… Consumer-facing: scoreboard, news, teams list, match summary. Pre-joined, ready to render.
Core sports.core.api.espn.com/v2/sports/soccer/leagues/{league}/… Normalized entity API. Individual teams, athletes, venues, groups, standings. Returns $ref links you dereference.
CDN cdn.espn.com/core/soccer/scoreboard?xhr=1&league={league} Pre-rendered page data bundle. Includes scoreboard + site chrome. Heavier payload, identical score data.
Recommendation for AgateTypes.com: The Site API is the best starting point — it returns pre-joined data (team names, logos, scores, venues all embedded) so you avoid chaining dozens of Core API $ref calls. Use the Core API for supplemental data like full rosters and athlete bios.

📋 Scoreboard — Scores & Schedule

The primary endpoint for fetching match results, live scores, and upcoming fixtures. This is the workhorse for a box-scores site.

Site API site.api.espn.com/apis/site/v2/sports/soccer/fifa.world/scoreboard

Returns the current day's events by default. Add date params to control the window.

Query Parameters

ParamExampleNotes
dates20260612Single date (YYYYMMDD). Returns games on that date.
dates20260611-20260720Date range. Returns all 104 WC matches when spanning full tournament.
limit200Max events to return. Default appears to be ~25. Use 200 for full tournament pull.

Box-score site play: A single call with ?dates=20260611-20260720&limit=200 returns all 104 matches. Filter client-side by status.type.state to separate upcoming / live / final. The geoBroadcasts array tells you which network carries each game (FOX, FS1, Telemundo, Peacock).

⚽ Match Summary — The Big One

The richest single endpoint. Returns everything for a given match: box score stats, rosters with player stats, key events (goals, cards), minute-by-minute commentary, odds, head-to-head history, and embedded group standings.

Site API site.api.espn.com/apis/site/v2/sports/soccer/fifa.world/summary?event={event_id}

Pass the event_id from the scoreboard response. Works for upcoming, live, and completed matches (more data after completion).

🏳️ Teams & Rosters

Site API site.api.espn.com/apis/site/v2/sports/soccer/fifa.world/teams

Returns all 48 qualified teams with IDs, abbreviations, logos, and links. Single call, no pagination.

Core API sports.core.api.espn.com/v2/sports/soccer/leagues/fifa.world/seasons/2026/teams/{team_id}

Individual team detail: colors, venue, group assignment, links. Returns $ref to athlete roster.

Core API sports.core.api.espn.com/v2/sports/soccer/leagues/fifa.world/seasons/2026/teams/{team_id}/athletes?limit=50

Full squad roster. Returns $ref links to individual athlete entries. 26-man squads typical.

Core API sports.core.api.espn.com/v2/sports/soccer/leagues/fifa.world/seasons/2026/athletes/{athlete_id}

Individual player bio: name, DOB, height, weight, citizenship, position, headshot URL, team link.

N+1 problem: The Core API roster returns $ref links, not inline data. For a 26-man squad, that's 26 sequential HTTP calls. Consider caching aggressively or using the summary endpoint's rosters field for match-day squads (which are inline).

📊 Groups & Standings

Core API sports.core.api.espn.com/v2/sports/soccer/leagues/fifa.world/seasons/2026/types/1/groups

Returns all 12 groups (A through L). Each group contains a $ref to its standings.

Core API sports.core.api.espn.com/v2/sports/soccer/leagues/fifa.world/seasons/2026/types/1/groups/{group_id}/standings/0

Full group table with all stat columns per team.

Predictable URL patterns for logos, flags, headshots, and league branding. All served from ESPN's CDN.

AssetURL PatternExample

Country flag (dark mode) a.espncdn.com/i/teamlogos/countries/500-dark/{code}.png …/500-dark/usa.png

Sizing: The /500/ path segment represents the image size. All flags/logos are 500×500px PNGs with transparent backgrounds — ideal for rendering at any scale. Player headshots are also large transparent PNGs.

Country Code Reference

The flag filename uses the lowercase ESPN abbreviation from the teams endpoint. A few that aren't obvious: South Korea → kors, Ivory Coast → civ (check the logo field in the API — it's always authoritative).

⚠️ Gotchas & Tips

Things to watch for

No API key, no SLA. These are undocumented, free ESPN endpoints. They could change without notice. No rate-limit headers are documented — be respectful with polling frequency.
Core API $ref pattern. The Core API returns everything as $ref links by default. Listing 48 teams returns 48 URLs, not 48 team objects. Budget for the N+1 calls or cache aggressively. The Site API avoids this by pre-joining data.
Status states for live scoring. The status.type.state field cycles through three values: "pre" (scheduled), "in" (in progress), "post" (final). The displayClock gives you the match minute during live play (e.g. "67'"). The status.type.detail field gives human-readable text like "Thu, June 11th at 3:00 PM EDT".
Polling strategy for live matches. Poll the scoreboard endpoint every 30–60 seconds during live matches. For detailed play-by-play, poll the summary endpoint for the specific event. The commentary array grows as the match progresses.
Rosters populate at different times. The match summary endpoint's rosters array is empty until lineups are announced (typically ~1 hour before kickoff). The Core API athletes endpoint has the broader tournament squad available now.
Date handling. All dates are UTC. The dates query param uses YYYYMMDD format. ESPN treats the date as the local broadcast date, so a late-night UTC match on Jun 12 shows up when you query 20260611 if it airs on Jun 11 in the US.
